# 대시보드 리디자인 스펙: Toss-style + 미래적

**날짜:** 2026-04-12  
**대상 파일:** `dashboard/app.py`  
**참고 레포:** `/tmp/awesome-design-systems`, `/tmp/awesome-design-md` (fintech 섹션: Coinbase, Stripe, Revolut, Wise)

---

## 1. 목표

현재 Streamlit 가계부 대시보드를 토스 앱처럼 심플하고 깔끔하면서 미래적인 디자인으로 변경한다.  
Python 데이터/비즈니스 로직은 전혀 수정하지 않고, **CSS 주입 + HTML 컴포넌트 교체**만으로 구현한다.

---

## 2. 디자인 결정 사항

| 항목 | 결정 | 비고 |
|------|------|------|
| 테마 | 라이트 + 다크 토글 | 세션 상태로 관리 |
| 내비게이션 | 파란 사이드바 (옵션 A) | 기존 #0064FF 유지 |
| 카드 스타일 | 플랫 + 굵은 타이포 (옵션 C) | 카드 없이 선+타이포로 구분 |

## 4. 타이포그래피

- **폰트:** `-apple-system, 'Pretendard', sans-serif`
- **페이지 제목:** 20–22px, weight 900, letter-spacing -0.6px
- **섹션 헤더:** 9–10px, weight 700, UPPERCASE, letter-spacing 0.8px  
  → 아래에 `border-bottom: 2px solid 주텍스트색` 라인
- **지표 숫자:** 18–24px, weight 900, letter-spacing -0.6px
- **델타(전월비):** 10px, weight 500
- **거래 항목명:** 12–13px, weight 700
- **거래 카테고리/날짜:** 10–11px, 보조 텍스트 색

## 5. 레이아웃 구조

### 홈 페이지
```
[헤더: 제목 + 날짜 | 다크모드 토글 | 동기화 버튼]
[구분선]
[수입 | 지출 | 순수익]  ← 카드 없이 그리드, 선으로 구분
[구분선]
[섹션 헤더: 카테고리별 지출]
[카테고리 그리드]       ← 아이콘 + 이름 + 금액, 선으로 구분
[구분선]
[섹션 헤더: 예산 현황]  ← 있을 때만
[예산 바]
[구분선]
[섹션 헤더: 최근 거래]
[거래 리스트]           ← 선 구분, 배경 없음
```

### 거래내역 페이지
```
[헤더: 제목]
[필터 행: 년도 | 월 | 카테고리]
[구분선]
[섹션 헤더: 거래 목록]
[data_editor]           ← 기존 유지, CSS 테마만 적용
[버튼 행: 저장 | 삭제 | CSV]
```

### 차트 / 설정 페이지
- 기존 구조 유지, 배경/텍스트/선 CSS만 테마에 맞게 적용

## 6. 다크 모드 토글 구현 방식

1. `st.session_state.dark_mode` (bool) 로 상태 관리
2. 홈 헤더 우측에 토글 버튼 배치 (`☀ 라이트` / `🌙 다크`)
3. 클릭 시 `st.rerun()` → 전체 CSS 재주입
4. CSS는 `dark_mode` 값에 따라 변수를 분기:
   ```python
   _BG    = "#0f0f13" if dark else "#fafafa"
   _TEXT  = "#ffffff" if dark else "#191F28"
   _SUB   = "#555566" if dark else "#8B95A1"
   _LINE  = "#2a2a35" if dark else "#E8ECF0"
   ```

## 7. HTML 컴포넌트 변경 목록

| 컴포넌트 | 변경 내용 |
|---------|----------|
| `_metric_card()` | 카드 박스 제거 → 플랫 그리드 셀, 선 구분 |
| `_section_header()` | 굵은 UPPERCASE + 하단 2px 선 |
| 거래 리스트 (홈) | 카드 박스 제거 → 선 구분 row |
| 카테고리 그리드 (홈) | 카드 박스 제거 → 플랫 셀 |
| 예산 바 (홈) | 카드 박스 제거 → 플랫 행 |
| 동기화 상태바 `_status_bar()` | 배경색 박스 → 인라인 텍스트 + 점 아이콘 |
| 사이드바 | 기존 CSS 유지, dark_mode 무관 |

## 8. 변경하지 않는 것

- 모든 Python 데이터 로직 (`db.*`, `categorize`, `load_rules` 등)
- 사이드바 내비게이션 구조 및 토글 (접기/펼치기)
- `st.data_editor` (거래내역 페이지)
- Altair 차트 (차트 페이지)
- 설정 페이지의 폼/입력 위젯
